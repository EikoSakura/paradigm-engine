# Roadmap

1. **Scaffold** — done. system.json, folder layout (module, templates, styles, lang, fonts), en.json, entry script registering the character actor type and the trait and technique item types with empty TypeDataModels. Installs and loads clean in a new V14 world.
2. **Data models** — done. Character actor plus the two item types, fields from the spec comment blocks.
3. **Item sheets** — done. View and edit modes from the item sheets mockup.
4. **Character sheet, view mode** — done. Layout and styling from the mockup. The Traits and Techniques panels render the embedded items. Fonts bundled locally (Shippori Mincho B1, Zen Kaku Gothic New, both OFL).
5. **Character sheet, edit mode** — done. Title bar toggle, all fields editable. Add creates an embedded item, a card opens its item sheet, delete removes it. Pips, Luck spent, Advancement boxes, and the unspent counter stay clickable in both modes.
6. **Adversary actor type** — done. Desire, Fear, Rank, the five Attributes, Hearts, Energy, embedded Traits and Techniques. Rivals add Luck Dice. Reuse sheet parts.
7. **Packaging** — done. Release zip, manifest and download URLs, install test from the manifest.
8. **Chat cards** — done. Item and roll cards from the chat cards mockup. Post buttons on the item sheet title bar and on each sheet card. Rolls start from an Attribute or Technique name in view mode; the Action Roll dialog picks the second die and a Trait, backed by a real Roll. No Difficulty, no outcome text.
9. **Party folder** — done. A Party folder in the Actors directory, created once per world. The Party HUD shows only the characters inside it (subfolders count), in directory order, instead of every player-owned character. The folder can be renamed or moved; membership follows the folder.
10. **Distance** — done. Token distance measured edge to edge and counted in tiles: one tile is the scene's distance setting, gridless scenes included, and within one tile the pair is Engaged. `game.system.api.getDistance(tokenA, tokenB)` returns units, tiles, engaged, and label. While a token drags, the ruler label counts the tiles of displacement from the drag origin. With one token controlled, hovering another visible token draws a tinted range line labeled with the distance. Display only. Replaces the earlier walls-and-regions feature, which a migration strips from old worlds.
11. **Rules revision** — done. Grade renamed to Rank everywhere; the Ch2 Special is Rank Up Rank, and a migration moves stored grades. Roll bands renamed Critical Success, Success, Failure; Fumble unchanged. Openings removed — Sync replaces them at the table, with no system piece. The named Distance steps retired for tile counts; Engaged survives and means adjacent tile. The Ladder gains Die Value (E 4, D 6, C 8, B 10, A 12, S 14) for Technique range, Technique area maximum, and Sync range through Bonds.
12. **Fumble, grid, Positioning** — done. The Luck rider reads "cannot alter". Every scene measures 1 tile per grid space, units "tiles": the system default for new scenes, a preCreate and preUpdate rewrite for created and imported maps (most arrive in feet), and a migration for existing ones. The grid is cardinal — square grids count diagonals as 2 (Rectilinear, the default and set by the migration) and the system's own measurement adds the axis gaps the same way. The per-die Rank Up and Rank Down steppers already in the roll dialog carry Flanking and High Ground. Move (base 5) and the creation trade: the sheet vitals gain a Move plate with an edit stepper, character Hearts, Energy, and Move steppers clamp 3 to 8, adversaries take a free-range Move of their own, and the creator's Finishing Touches trade the three one for one — floor 3, cap 8, total 17 — with a Free counter that gates Create Character.
13. **Bond Ranks, Move advancement** — done. Bonds are a name and a Rank, E to S — the number and the sentence both go. A character starts with one Bond at E and holds at most six; Invoke at the table rolls the Bond's Rank die to replace one Luck Die, or activates a Sync, with no system piece. No growth channel yet: the Rank stays hand-editable, no automation. A migration maps stored numbers 1 to 6 onto E to S (6 is S) and deletes the number and sentence fields. The Standard Advancements list gains +1 Move, one box, under New Energy; Move stays capped at 8.
14. **Energy** — no build needed. A Technique's Energy cost equals its Rank number, 1 for E through 6 for S — the Ladder's mod column already prices it, so sheets, creator, and cards read right. The rest is table rules with no system piece: a Combo replenishes 1 Energy, Charge spends the action to recover 2, Scene end recovers 1, and a completed Relaxation Scene or Episode end restores all.
15. **Adversaries** — done. The stat line is Desire, Fear, Rank — public, the Difficulty to act against it — the five Attributes, Hearts, Energy, Move, Traits, and Techniques; pools and Move are Storyteller-set with the character line of 6, 6, and 5 as reference, so adversaries gain Move alongside the character Move build. Adversary results carry two rows only: at the Difficulty and above it gets what it is aiming for, below it does not, and a Fumble fails — so adversary roll cards drop the Critical band and every rider, and Opening creation is already gone. Getting what it is aiming for costs the target 1 Heart, and adversaries can Limit Break — rules text. Rivals keep three Luck Dice by character rules and re-rank on return, both already in place.
16. **Contests, Limit Break** — no build needed. Limit Break mechanics are unchanged and the band names already read Critical Success and Success.
17. **Areas** — done. An area Technique covers tiles within its reach, no wider than its Die Value from the point of origin; everything covered is a target unless the description says otherwise. One roll for the whole area, compared to each Difficulty within; the Spotlight reads the highest Difficulty among the targets — table rules, no automation. The build: an Area checkbox on Techniques and Traits in the item header's chip row, and an Area chip on the item sheet, sheet cards, and chat cards; clicking it opens the Size dialog — 1 to the item's Die Value, default the Die Value, counted in Tiles — and Place previews the burst on the canvas: a click drops it, Escape or a right click cancels. V14 keeps Measured Templates as previews only, so the dropped burst persists as a polygon Drawing in the user's color — the cardinal staircase diamond, corner-anchored on even widths and center-anchored on odd — moved and cleared with the core drawing tools. Below the Trusted drawing permission the shape flashes for a moment instead of persisting. When the rolled Technique is an area one — first or second die — the Roll Dialog carries the same Size stepper and Place button, so one window covers the whole activation; the chip stays for Traits and for placing without a roll.
18. **Ranks panel, description commit** — done. The sheet's Ladder panel is titled Ranks and its header row sits on an ink band. The S die is d12+2, so its Die Value 14 reads straight off the die; SS stays Difficulty 22. Item descriptions edited from a character's sheet commit reliably: leaving Edit or closing the window submits the open editor, and a mid-edit re-render — a stepper, a new Ruling — carries the unsaved text across instead of dropping it.
19. **Free vitals, creator resume** — done. Hearts, Energy, and Move on the sheets run free from 0 with no cap, characters and adversaries alike; the 3-to-8 trade totalling 17 lives in the Character Creator alone. The creator seeds from the actor — name, Attributes, first two Traits and Techniques, Bond, pools, Luck — and keeps every change on an actor flag, so reopening resumes the selections for editing instead of starting over. Create Character is safe to run again: grown Rank, extra Bonds, and Luck Die sizes survive, and only the creator's own Trait and Technique rows are replaced.
20. **Tension removed** — done. Tension is out of the game, so the meter, its settings menu, the Announce and Auto Gain options, the gain chips, and the Tension rider lines on roll cards are gone; Success carries no rider, Failure the Spotlight, Fumble the Spotlight and Luck. The Tracks board docks top center where the meter stood. A migration deletes the stored Tension settings and the applied marks on old roll cards. Its mockups are deleted.
21. **Tracks removed** — done. Tracks are out of the game, so the Tracks board, the New Track dialog, Contests, Escalations, the scene-control toggle, the fill and erase chips on roll cards, and the Adversary Builder's Desire Track option are gone. A migration deletes the stored Track list and the applied marks on old roll cards. Its mockups are deleted.
22. **Mockups removed** — done. Every mockup HTML file is deleted from the repo and the folder, the ignored ones included; the system code is the only reference.
23. **Traits removed, Techniques renamed Skills** — done. Traits are out of the game: the Item type, its sheet panel, the Ranks table's bonus column, the Trait pick and bonus on the Action Roll and its card, the creator and builder steps, the hotbar's Trait slots, and the New Trait and Rank Up Trait advancements are gone. Techniques are Skills everywhere — Item type `skill`, the Skills panel, the Skill bar and its keybindings, New Skill and Rank Up Skill, the lang keys and CSS. A migration deletes Trait Items, retypes Technique Items to Skills with their data intact, clears emptied hotbar slots, and moves the advancement boxes to the Skill keys; the character model carries the old box keys forward on load so nothing is lost before it runs. Legacy `-=` deletion keys in the migrations give way to the V14 ForcedDeletion operator.
